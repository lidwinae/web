Clean & Clear Glass

Cleaner, clearer, and connected vanilla glass.

Overview

Vanilla glass that responds to the glass beside it.

Clean & Clear Glass is a client-side visual mod that makes vanilla glass blocks and glass panes look cleaner and visually connected.

Matching connected glass hides its internal borders while exposed outer borders remain visible. This creates clearer windows, glass walls, and larger glass structures without adding new blocks or changing gameplay.

The mod keeps the original vanilla block and item IDs. It only changes how relevant glass models are rendered on the client.

Features

One focused visual change.

Connected blocks

Matching glass blocks hide shared internal faces and keep the exposed outer border.

Connected panes

Glass panes receive clean arms, outer edges, and improved center intersections.

All stained colors

Every vanilla stained glass block and pane color is supported.

Client-side only

The mod does not change game rules and can be used while joining vanilla servers.

No separate CTM mod

The connected rendering is implemented directly by Clean & Clear Glass.

Configurable

The rendering can be turned off and available glass styles can be changed in-game.

Appearance

Choose how much surface detail remains visible.

Clear regular glass

Keeps the center clear for the cleanest and most open appearance. This is the default regular glass style.

Subtle regular glass

Adds a small center detail when connected glass forms a suitable pattern such as a 2×2 area.

Tinted glass styles

Supported versions offer Subtle, Visible, and Clear options. Subtle is the default.

Open settings: press Alt + G.

The shortcut can be changed under Options → Controls → Key Binds. Fabric users can also open settings through Mod Menu when it is installed.

Installation

Install it like a normal client-side mod.

Fabric

  1. Install Fabric Loader for your Minecraft version.
  2. Install Fabric API.
  3. Download the matching Fabric file.
  4. Put both files inside the mods folder.
  5. Launch Minecraft with the Fabric profile.

NeoForge

  1. Install NeoForge for your exact Minecraft version.
  2. Download the matching NeoForge file.
  3. Put the mod file inside the mods folder.
  4. Launch Minecraft with the NeoForge profile.

Fabric and NeoForge files are not interchangeable. Always use the file made for your exact loader and Minecraft version.
